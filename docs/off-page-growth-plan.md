# A Lyme Life — Off-Page Growth Plan (SEO + GEO)

_Last updated: 2026-09-29_

**Why this doc exists:** After ~6 months, on-page work has taken the site from
1 → ~107 ranking keywords, but organic **traffic is still near zero**. This plan
is the honest diagnosis of why, and the off-page work that actually moves the
needle — for both classic search (SEO) and AI answers (GEO). It supersedes the
scattered growth notes; `backlink-targets.md` remains the detailed target list.

**Diagnosis:** This is not a channel-selection problem (SEO vs GEO). It's an
**authority + reach** problem. Nothing authoritative references the site, so it
ranks page 4–7 and gets no clicks; the same deficit limits AI citations. The
machine converts — it just needs real humans at the top of the funnel.

**Key point:** SEO and GEO share ~90% of the same inputs. "Switch to GEO only"
would rename the problem, not fix it. The fix is off-page authority + Christina's
own reach, which lift **both** at once.

## The plan — off-page, in priority order

### 1. Put out the fire: the toxic backlink profile 🔴
The backlink profile is 94% spam, which actively suppresses the domain.
- [ ] **Confirm the disavow file is actually submitted** in Google Search
      Console (`docs/disavow-alymelife.txt` was drafted months ago). If it
      hasn't been uploaded, this is very likely the single highest-impact
      action available. Disavow doesn't remove links — it tells Google to
      ignore them — so submission is the whole point.
- [ ] Re-audit the profile in ~60 days; add any new spam domains and re-submit.

### 2. Earn real citations & links (helps SEO + GEO equally) 🟡
Work `backlink-targets.md` top-down. Highest ROI first:
- [ ] **Tier 6 quick wins — partner links.** Confirm followed links to
      alymelife.com from **thelymespecialist.com** and **lymeimmunotherapy.com**
      bios, and request the **reciprocal followed link to the new
      `lyme-immunotherapy.html` page** (both partners already get cited by AI —
      a link from them is doubly valuable now).
- [ ] **Tick Boot Camp podcast** — pitch Christina (patient-#1 / relapse story).
      Show-notes backlink + warm audience. Highest single ROI.
- [ ] **HARO / Qwoted / Featured** — answer journalist queries on Lyme,
      misdiagnosis, medical travel. Christina is a quotable source.
- [ ] Target **2–4 quality links/month**. Authority compounds over months.

### 3. Activate Christina's existing reach (fastest path to real humans) 🟢
This is the biggest untapped asset and it feeds both leads *and* GEO signal.
- [ ] **YouTube** — dozens of videos, a real audience, barely pointed at the
      site. Add alymelife.com links to the channel About + every video
      description (link the *specific relevant page*, not just the homepage).
      YouTube is heavily used by both Google and AI engines as a source.
- [ ] **Reddit (r/Lyme, r/lymedisease), Facebook Lyme groups, Quora** —
      participate genuinely; share the specific resource where it helps. These
      are exactly where AI engines pull "real patient experience," and where
      Christina's story converts. Never spam.
- [ ] **Inspire.com / HealthUnlocked** Lyme communities — same idea.

### 4. GEO-specific plays (ride on #1–3, plus these)
- [ ] Keep publishing **unique, first-person, extractable** content on emerging
      treatments (Treg, immunotherapy, apheresis, hyperthermia) — the niche
      where the site already gets cited and institutional sources are thin.
- [ ] Get referenced on the source types AI actually pulls for this topic:
      **news/media** human-interest stories, **foundation blogs**
      (bayarealyme-style), and **practitioner explainers** (betterhealthguy-style).
- [ ] Maintain FAQ/speakable/`MedicalWebPage` schema on every new page (done as
      standard) — it's the extractable format AI engines favor.

### 5. Paid — the near-term lead bridge (operator decision)
Organic of either flavor is a 6–18 month game. If leads are needed sooner, run
**Google Ads on the commercial terms** (`chronic lyme disease treatment`,
`lyme disease treatment center(s)`, hyperthermia terms) → the strongest landing
pages, while authority builds underneath.

## Honest expectations
No on-page pass moves a page-5 ranking to page 1 by itself. The durable levers
are **authority (#1–2)** and **reach (#3)**, measured in months. The bright
spots: the funnel converts, and the site already earns AI citations in its
niche — both say the foundation is sound and the missing piece is off-page.
